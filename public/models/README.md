# Modelo humano experimental (CC0)

Arquivo: `public/models/human-male.glb`

- Autor original: Orange Juice Games
- Distribuição: https://orange-juice-games.itch.io/male-base-mesh
- Espelho utilizado: https://github.com/BoQsc/Godot-3D-Male-Base-Mesh/blob/main/Original/male_base_mesh.glb
- Licença declarada pelo autor e espelho: Creative Commons Zero (CC0 1.0)
- O arquivo é uma **malha masculina simples**, com esqueleto e UVs. Não é fotorrealista e não inclui os morph targets para medidas.
- O aplicativo mantém a V13 em `main`; o modelo deve permanecer **experimental** enquanto for calibrado e aprimorado no Blender.
- Para testar: na branch de desenvolvimento, entrar em Corpo → Avatar individual → Novo avatar (teste). Um modelo de amostra será carregado automaticamente; também é possível selecionar outro arquivo GLB.

**Atenção:** o arquivo GLB atual serve para comprovar o pipeline de modelos humanos. Não deve ser apresentado como resultado anatômico final. O próximo passo é criar shape keys compatíveis em Blender e verificar a qualidade de pele e musculatura.
